# 共有レビュー(4) クラブ入力の修正

## 確認元と採用する内容

指定されたGoogleスプレッドシート「jmrc-review-notes (4)」を確認元とします。24画面のうち、クラブ年度登録の1行に修正メモがあり、残る23行は確認待ちでした。先に共有されたCSVとも24行の内容が一致します。空欄の列は空文字として比較しています。

確定した修正は次の3点です。

| 修正 | 反映する内容 |
| --- | --- |
| JAF登録番号 | 操作確認画面の「不変の5桁コード」を「JAF登録番号（5桁）」へ変更。正式申請にある5桁のクラブ・団体登録番号と同じ呼び名にする |
| 他地区の所属支部 | 「その他の所属支部」を「他地区の場合の所属支部」へ変更。近畿6支部以外の所属先を入力する既存の欄を使う |
| 代表者と連絡先 | 「クラブの情報」「代表者の情報」「連絡先の情報」の順に分ける。兼任の選択を連絡先欄より前に置き、同じ場合は連絡先の再入力を省略できるようにする |

元メモの「4．」には内容がありません。追加があれば指定表のH2に記入し、追加がなければ「追加なし」と回答できるようにしました。原文のA～E列と24行は残し、F列に対応状況、G列に質問、H列に追加回答欄を設けています。既存の要件回答表にはN18として確認元と対応状況を記録し、同じ質問を別の回答欄へ重ねていません。

23行の「確認待ち」は承認済みと扱いません。確認票に残る古い説明文も、後から確定したL12の料金や既存の回答を取り消す指示と扱いません。

## 変更する範囲

操作確認画面、正式なクラブ申請、会計のクラブ入力例で表示名を統一します。操作確認画面の番号欄は先頭の0を残す文字列のまま、5桁を検証します。入力エラーの案内もJAF登録番号という呼び名にそろえます。

正式申請と操作確認画面はfieldsetとlegendで入力項目を分け、見た目とキーボードで移る順をそろえます。代表者が連絡先を兼ねる場合、JavaScriptを使えない場合もサーバーが代表者情報を転記します。別の担当者の場合は連絡先の必須項目をサーバーで検証します。

保存キー、正式入力の正規化順、暗号保存と再送判定、既存アカウントの権限は変えません。所属支部や所在地から正会員・賛助を自動決定せず、他地域のJMRC主催クラブの例外を維持します。

正会員団体5・6・8の年会費20,000円、7の加盟対象外、新規入会金10,000円・更新/再加入0円は維持します。賛助団体の料金、受付開始、年度資格の正本切替、一般公開・実メール送信・削除実行は保留です。

## 事務局の確認方法

1. 既存のアカウントで `/manage/` にサインインします。
2. 「クラブ登録の申請」を開き、クラブ・代表者・連絡先の順と、他地区の欄の名前を確認します。受付は停止したままなので申請を提出しません。
3. 事務局は「機能の操作確認」から「正会員クラブの年度登録」を開きます。JAF登録番号（5桁）の表示と、代表者・連絡先の入力順を確認します。
4. 代表者と連絡先が同じ場合の選択を確認します。操作を試すときは架空の確認画面か隔離環境を使い、本番へ架空の申請・請求・入金を作らないでください。
5. 4点目の追加要望は指定表のH2へ記入します。画面確認と受付開始の承認は別です。
