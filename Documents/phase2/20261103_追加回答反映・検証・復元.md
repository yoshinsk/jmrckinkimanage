## 復元時の注意

先にDB管理CLIの `snapshot` を取得し、適用記録の `after` と一致することを確認します。申告データや権限に後続変更がある場合、削除せずに停止します。

復元順序は「追加した保険説明2ファイル → 先に配置した21ファイル → DBの限定変更」です。新コードが残った状態で列を削除してはいけません。既存entryや共有DB全体を過去のバックアップで上書きする手順ではありません。

コードはバックアップ内の `deploy_information_preview.py --profile confirmed --rollback <コードのバックアップ先>` で戻します。その後、非公開バックアップ内の `confirmed_answers_database.php rollback` に `database.json` を標準入力で渡します。接続情報は管理プロセスの環境変数だけで渡し、記録やコマンド引数にパスワードを残しません。

DB復元は権限定義・権限割当を元へ戻し、今回追加した空の表・列だけを除去します。初期設定を行った事実の監査ログは残します。復元後も既存ログインと保留設定を確認してください。

## 今回の版を戻すコマンド

対象サーバーへSSH接続した後、管理者が次の一式を実行します。後続のデータ・権限・コード変更がある場合は停止します。停止時は条件を外さず、変更内容を確認してください。

```bash
sudo python3 - <<'PY'
# 今回の追加回答反映だけを復元する。共有DB全体やentryは復元しない。
import json, os, subprocess
from pathlib import Path
notices = Path('/var/www/vhosts/gymkinki.com/private/jmrc-portal-backups/insurance-notices-20261103T085821Z')
code = Path('/var/www/vhosts/gymkinki.com/private/jmrc-portal-backups/confirmed-answers-20261103T084115Z')
db = Path('/var/www/vhosts/gymkinki.com/private/jmrc-portal-backups/confirmed-answers-db-20261103T084106Z')
record = json.loads((db / 'database.json').read_text())
env = os.environ.copy()
env['MYSQL_PWD'] = Path('/etc/psa/.psa.shadow').read_text().strip()
env['JMRC_RELEASE_DATABASE'] = 'jmrckinki'
env['JMRC_RELEASE_DB_USER'] = 'admin'
cli = ['/opt/plesk/php/8.4/bin/php', str(db / 'confirmed_answers_database.php')]
# 後続変更がないことを、コード復元に着手する前にも確認する。
current = json.loads(subprocess.run(cli + ['snapshot'], env=env,
    capture_output=True, check=True).stdout)
assert current == record['after'], '後続変更あり。復元を中止します。'
# 後から配置した保険説明2ファイルを先に戻す。
subprocess.run(['python3', str(notices / 'deploy_information_preview.py'),
    '--profile', 'insurance-notices', '--rollback', str(notices)], check=True)
subprocess.run(['python3', str(code / 'deploy_information_preview.py'),
    '--profile', 'confirmed', '--rollback', str(code)], check=True)
# 旧コードへ戻した後にだけ、今回追加した空の構造を除去する。
subprocess.run(cli + ['rollback'], input=(db / 'database.json').read_bytes(),
    env=env, check=True)
restored = json.loads(subprocess.run(cli + ['snapshot'], env=env,
    capture_output=True, check=True).stdout)
assert restored == record['before'], '復元後の照合が必要です。'
print('コードとDBの限定復元が完了しました。既存ログインも確認してください。')
PY
```
