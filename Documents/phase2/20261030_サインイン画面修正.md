# サインイン画面のスマートフォン表示修正

実施日: 2026年10月30日

## 修正内容

共通認証を導入した際に、サインインフォームから既存Bootstrapのクラスが外れていました。スマートフォンではラベルと入力欄が横並びになり、パスワード欄とボタンが同じ行に詰まっていました。

既存 `jmrckinki/httpdocs/entry/login.php` のレイアウトに合わせ、項目ごとの縦配置、画面幅に収まる入力欄、項目間の余白、青いボタン、パスワード再設定の案内を復元しました。ラベルと入力欄は `for` / `id` で対応付けています。エラー表示には既存の警告スタイルと `role="alert"` を設定しました。

認証処理、CSRF、許可済み戻り先、共通セッション、既存パスワードの扱いは変更していません。HTML標準の必須入力・メール形式の検証を維持しています。

修正コードの全文: [integration/jmrckinki/login.php](../../integration/jmrckinki/login.php)

## 復元手順

修正前ファイルと復元用スクリプトは、サーバー内の次の非公開ディレクトリに保存しました。ディレクトリはrootのみアクセス可能で、ファイル権限は0600です。

`/var/www/vhosts/gymkinki.com/private/jmrc-portal-backups/login-layout-20261030T003617Z`

必要時は次のコマンドを実行します。

```sh
sudo python3 /var/www/vhosts/gymkinki.com/private/jmrc-portal-backups/login-layout-20261030T003617Z/deploy_login.py --rollback
```

復元処理は対象ファイルの現在のハッシュを確認します。今回の修正後に別の変更があれば停止します。バックアップのハッシュとPHP構文を確認して元のログイン画面だけを戻し、対象OPcacheを無効化します。DB、認証設定、セッションは戻しません。スクリプトの構文確認は実施済みですが、復元そのものは本番では実行していません。
