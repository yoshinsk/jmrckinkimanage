# C07 他地域主催クラブの例外確認・検証・復元

2026年11月3日のチャット回答「他地域の主催クラブは正会員という例外を維持する」を、2027年度の要件と確認画面に反映しました。元の質問で示した、旧HP会則第5条の「JMRC近畿の事業として競技会を主催する他地域のJAF登録クラブ」という条件を維持しています。

## 確定した判定

対象は近畿地区外のクラブです。一般の競技会を主催しているだけでは例外に該当しません。

| JAF登録クラブ | JMRC近畿の事業として主催 | 結果 |
| --- | --- | --- |
| はい | はい | 正会員 |
| いいえ | はい・いいえ・不明 | 賛助会員 |
| はい・不明 | いいえ | 賛助会員 |
| はい | 不明 | 保留 |
| 不明 | はい・不明 | 保留 |

両条件が必要なので、一方が明確に非該当なら例外は成立しません。例外の成否を判断できない組み合わせは、賛助会員に決めつけず保留にします。2028年度以降、近畿地区内のクラブ、関連団体・企業へ、この判定を自動適用しません。

## 事務局の確認方法

1. 本番の [マイページ](https://gymkinki.com/manage/) に既存アカウントでサインインします。
2. 「機能の操作確認」→「正会員クラブの年度登録」を開きます。
3. 「他地域クラブの会員区分」で2項目を選び、「他地域クラブの区分を確認」を押します。
4. 両方「はい」で正会員、主催を「いいえ」にすると賛助会員、主催を「確認できていない」にすると保留になることを確認します。
5. 料金を試す場合は、表示された結果に合わせて「料金計算の会員区分」を選びます。気づいた点は確認メモへ記入し、終了前にCSVへ保存して担当者へ渡してください。

入力は確認画面内だけで使います。既存のクラブ区分・請求・入金・個人会員資格は変更しません。賛助の数字コード対応と正式登録への接続は保留です。確認メモの保存だけでは、他の担当者へ共有されません。

## 検証と本番反映

変更対象は、区分判定部品、確定回答カタログ、確認画面の定義・処理・表示の5ファイルです。DB変更と受付開始は行いません。以前の初期権限設定や保険説明の反映も、そのまま維持します。

隔離環境で条件の9通り、翌年度の拒否、不正入力の拒否、確認用の請求・資格を変更しないこと、スマートフォンでの操作を検証します。本番はGET中心で検証し、通常のサインイン・サインアウト以外のPOSTを行いません。

## この変更だけを戻す手順

本番適用時に、5ファイルの原本・配置前のハッシュ・保護状態と復元用スクリプトを、非公開ディレクトリへ保存します。ディレクトリは700、ファイルは600で保護します。

対象サーバーにSSH接続後、管理者がバックアップ内の `deploy_information_preview.py --profile club-region --rollback <今回のバックアップ先>` を実行します。後続のコード変更がある場合は停止します。共有DB全体の復元や前回の権限設定の取消しは不要です。

配置後・復元後とも、既存のログイン、事務局だけが確認画面を閲覧できること、受付保留が維持されていることを確認してください。今回の適用結果とバックアップ先は、次のとおりです。
