# クラブ受付の事務局向け操作手順

対象：2027年度クラブ登録。2026年11月16日作成。クラブの受付開始はまだ承認・実行していません。

## 最初に確認すること

クラブの新規申請は2026年12月1日0:00から、2027年2月7日23:59:59までを予定しています。すべて日本時間です。2月8日0:00は受付期間外です。日付が12月1日になっても、受付の保留設定が残っていれば提出できません。この確認画面から受付を開くことはできません。

クラブ受付と、個人会費・年度資格の参照元の切替は別の条件です。12月のクラブ受付を理由に個人の参照元を前倒しで切り替えません。2027年1月1日に個人受付と同時に切り替える方針で、切替作業と総合受入は別に残っています。

現在の連絡窓口は既存回答どおり事務局、運用責任者は運営委員長です。掲載するメールアドレス・電話番号・対応時間、技術担当への連絡方法は未確定です。共有回答表の追加確認欄で指定してもらい、決まるまで独自の連絡先を案内しません。

## 画面の開き方

1. [ポータル](https://gymkinki.com/manage/)へ、事務局用の既存アカウントでサインインします。新しい共用アカウントは作りません。
2. マイページの「事務局の設定」から「運用開始前の確認」を開きます。
3. 「クラブ受付の日程・手順」を押します。[日程・手順画面](https://gymkinki.com/manage/preparation.php?section=club_opening)から直接開くこともできます。
4. 「確認する年度」を2027にして「日程を確認する」を押します。表示は確認するたびに現在の設定を読み直します。

| 画面の表示 | 読み方 |
| --- | --- |
| 日程上の状態：開始前 | 受付開始時刻になっていません |
| 日程上の状態：受付期間内 | 日程の範囲内です。これだけでは開始承認や設定の完了を意味しません |
| クラブ受付の設定：保留中 | 期間内でも新規提出できません |
| 現在の新規提出：提出できません | 日程・設定・年度の参照元の条件がそろっていません。運営者の開始判断を確認します |
| 日程上の状態：締切後 | 新しい申請は提出できません。例外の延長は行いません |
| 日程の確認が必要 | 開始・締切などの設定を技術担当へ確認します |
| 振込先設定：0件または複数件 | 正式な案内を出す前に用途・年度・有効期間・重複を確認します |

料金や振込先の「件数」は登録状況です。金額や口座内容が正しいこと、担当者が手順を確認したことの代わりにはなりません。口座本文・暗号鍵・個人情報はこの画面に表示しません。

## 開始前の確認表

未完了の欄がある場合は運営者へ報告し、受付を開きません。以下を確認しても、自動で受付が始まることはありません。

| 確認項目 | 担当と確認方法 | 未完了の場合 |
| --- | --- | --- |
| 対象年度・開始・締切 | 事務局が日程画面で2027年度と日本時間を確認 | 技術担当へ設定を確認 |
| 本人のサインイン | 既存クラブ担当者が自分のアカウントで確認。メール確認・停止状態も確認 | 事務局へ連絡。パスワードを共有しない |
| クラブ情報の再利用 | 「クラブ登録の申請」で「既存エントリーのクラブ情報を使う」を確認 | 元情報と追加入力を本人・事務局で確認 |
| 年会費と入会金 | 事務局が正会員/賛助、JAF区分、新規/更新/再加入の金額を確認 | 料金を推測して請求しない |
| 正式振込先と手動確認の開始承認 | L03の回答、実口座・適用年度を事務局が確認 | 仮口座を使わず保留 |
| 担当者の権限と操作 | 事務局・財務・クラブ本人が隔離環境で申請から承認・訂正まで確認 | 実アカウントへの権限付与・受入を別途実施 |
| 締切後の処理と連絡体制 | 再申請・入金・承認の期限、連絡先・対応時間を運営側で指定 | 未確定の運用を開始しない |
| 障害復元の準備 | 技術担当が固定対象、原本、変更前後のハッシュと戻し方を確認 | 復元記録を準備し、開始判断へ報告 |

既存クラブの事前照合は本人が申請するための条件にしません。更新候補の選択は入力補助であり、既存クラブの操作権限を自動で付けるものでもありません。

## 申請の照合と差し戻し

以下は受付開始が承認され、必要な設定が整った後の手順です。現在は本番で申請を作って練習しません。

1. 「クラブ登録の申請」で事務局の一覧を開き、申請番号と年度を確認します。
2. 新規/更新/再加入、正会員/賛助、JAF番号5桁とJAF区分を、本人の申請と資料で照合します。更新候補を選んである場合も確認します。
3. 誤りがあれば、訂正してほしい項目と理由を書いて差し戻します。本人が訂正して再申請するまで年度登録へ接続しません。
4. 正しい内容と既存クラブの対応を確認した後、確認欄にチェックして年度登録へ接続します。似た名前だけで他のクラブへ接続しません。
5. 古い画面のまま操作して「別の更新」が出た場合は、申請一覧から最新の内容を開き直します。

締切前に提出した申請を締切後に差し戻す場合の再申請期限は未確定です。新しい申請を作り直す、受付を延長する、事務局が勝手に期限を決める対応はしません。運営判断を確認します。入金・年度承認の締切も新規提出の締切と同じとは決めていません。

## 請求・入金確認・年度承認

1. 照合した申請の「振込先・入金・承認状況を確認する」またはマイページの「クラブ会費・承認」を開きます。
2. 年会費・入会金を確認します。正式振込先の準備後に請求を発行し、請求時の口座案内を確認します。後から口座設定が変わっても、発行済みの案内は勝手に差し替えません。
3. 事務局または財務が銀行明細を確認し、実際の入金日・金額・取引番号を入力して記録します。振込名義の末尾IDは銀行の取引番号とは別です。
4. 不足があれば残額を確認し、過入金は未充当額として保持します。同じ入金を新しい取引として登録し直しません。
5. 満額入金後に、年度承認権限を持つ事務局担当者が確認欄にチェックして承認します。本人や財務専用権限による自己承認はできません。
6. 「年度登録済み」と「現在の資格」を確認します。開始前の年度登録や、個人会費の正本が未切替の段階では、登録済みでも現在の資格は有効になりません。

入金の訂正は元の正の充当と理由を指定して行い、必要なら同じ請求へ再充当します。元の記録を消す処理、実返金、別クラブや別口座への振替は行いません。訂正後はクラブと配下の個人資格を再判定します。詳しい入力手順は[会費・承認の操作手順](20261116_クラブ会計接続と既存登録情報の再利用.md)を参照してください。

## 送信の重複や権限エラー

| 起きたこと | 最初に行うこと | 避けること |
| --- | --- | --- |
| 送信後に画面が止まった | 同じアカウントで申請一覧を確認し、既存の申請番号を確認 | 不明なまま新規申請を繰り返す |
| 同じ送信を再実行した | 同じ処理キー・同じ内容なら元の結果を確認。締切後も新規登録は増えない | 再送を理由に新規受付期限を延ばす |
| 処理キーが別の内容で使用済み | 最新の申請を開き、内容と申請番号を事務局へ伝える | 別人の申請を上書きする |
| 他人の申請を開けない | 本人・担当クラブ・職務権限を確認 | 他人のIDやパスワードを借りる |
| 事務局の権限が使えなくなった | 任期・承認状態・取消・有効期限を確認 | 旧entry管理者の権限だけで代用する |
| 口座未設定で請求できない | 正式口座とL03の開始承認を確認 | 仮の口座や過去の別用途口座を使う |

## 障害時の連絡と復元

1. 発生した日本時間、画面名、申請番号、行った操作、表示されたエラーを記録します。パスワード・口座番号・個人名簿を問い合わせへ貼り付けません。
2. 事務局が内容を確認し、運営委員長へ運用判断を依頼します。技術担当への連絡先は運営側で確定した方法を使います。
3. 技術担当が今回の変更と、その後に行われた別の変更・実業務を分けて確認します。既存エントリー・ダート受付をポータルの保留だけを理由に止めません。
4. 必要な場合だけ、今回の固定対象ファイルを非公開バックアップから復元します。後続の変更がある場合は自動で上書きしません。
5. サインイン、クラブ画面、既存エントリー、ダートの受付状態、業務表・設定の一致を読み取り確認します。本番に架空の申請・請求・入金を作って確認しません。

今回の変更は確認画面の2ファイルだけで、DB・受付設定・権限は変更しません。DB全体のバックアップを通常の画面復元として上書きしません。対象ファイルと復元コマンド、隔離試験と本番確認の結果は[検証・復元記録](phase2/20261116_C7境界試験・運用準備・検証復元.md)へ記録します。
