# 事務局の操作確認ガイド

2026年11月1日更新。画面に慣れていない方向けに、最初の操作と回答の残し方をまとめました。

## まず開く場所

1. [ポータル](https://gymkinki.com/manage/)で、いつものアカウントでサインインします。
2. マイページの「事務局の設定」から「機能の操作確認」を押します。[確認画面を直接開く](https://gymkinki.com/manage/review.php)こともできます。
3. 「操作確認専用・架空データ」と表示されていることを確かめます。

事務局権限のある方だけが入れます。練習用の24画面なので、実際の会員登録・入金・資格変更・メール送信は行われません。氏名や口座は、画面に入っている架空の例を使ってください。

## 入力せずに、会員証を確認する

1. 一覧の「会員証の例を見る」を押します。入力は不要です。
2. 氏名・会員番号と「有効」が表示されます。これは承認と入金が済んだ架空の例です。本物の会員証やQRは発行されません。
3. 上の「確認画面の一覧」を押し、「会費請求・入金確認・訂正」を開きます。
4. 「最後の入金を取り消す」を押します。会員資格が無効になる表示を確認します。
5. もう一度有効な会員証を見たいときは、一覧へ戻り「会員証の例を見る」を押します。

このボタンは確認中の申請・入金の例を入れ替えます。各画面に書いた確認メモは残ります。入金番号を考えたり、実際に振り込んだりする必要はありません。

## 気づいたことを担当者へ伝える

1. 気になる画面の下にある「運営者の確認メモ」へ、困った点や直したい点を書きます。
2. 「確認メモを保存」を押します。例：「会員証は見られたが、入金取消後の説明が分かりにくい」。
3. 終了前に、上の「確認メモをExcel用CSVに保存」を押します。24画面分の確認票がファイルとして保存されます。
4. 保存したファイルをExcelで開き、内容を確かめてから、いつもの方法で運営担当者へ渡してください。

「確認メモを保存」だけでは、他の担当者には届きません。メモはこのブラウザーで一時的に保存されます。2時間経過後の再表示・サインアウト・初期化で使えなくなるため、終了前にファイルを保存してください。「確認メモをJSONに保存」は技術担当者向けで、通常は使う必要がありません。

保存先が分からない場合は、パソコンではブラウザーのダウンロード一覧、スマートフォンではブラウザーのダウンロード一覧や「ファイル」アプリを確認してください。保存場所は端末の設定で異なります。

[Google回答表](https://docs.google.com/spreadsheets/d/1z0WuTupTRBSXgzMNBRjosTNgOi13HyVPYtn1knIsato/edit#gid=202611011)の「整合性チェック_20261101」には、資料の食い違いと残る確認事項をまとめています。黄色の「運営側の回答」と「回答者・日付」に記入してください。こちらはGoogle上で共有され、確認画面のメモとは別です。「画面の使い方_20261101」タブにも操作手順を載せています。

## 別の立場や状態を確認する

上の「確認する立場」を押し、「立場を切り替える」で事務局・クラブ代表・個人会員・財務委員・公開閲覧者を選び、「立場を変更」を押します。これは練習画面内の切り替えで、実際のアカウント権限は変わりません。公開閲覧者には、有効な会員証の氏名と番号だけを表示します。

一部の操作やダウンロードは事務局の立場でだけ使えます。ボタンが見つからない場合は、事務局に戻してください。

「年度設定・権限・移行・保存方針」では、承認待ち・未入金・資格停止・期間終了などの例を選び、「状態例を表示する」で比べられます。「架空の確認日」は実際の今日とは別で、資格の表示に影響します。

| 画面の表示 | 意味 |
| --- | --- |
| 業務処理あり | 仕組みを隔離環境で検証済み。この場所での操作は説明用 |
| 画面試作 | 見た目と操作手順を確認する段階 |
| 運用確認 | 方針を説明する段階 |

どの表示でも、この確認画面から本番の受付が始まることはありません。「画面の流れを確認」という回答も、受付開始や規程承認を意味しません。

## 申請から順番に試したい方へ

先に確認メモをファイルに保存してから、下の「確認用の操作履歴と初期化」を開いて初期化します。初期化するとメモも消えます。

1. 正会員クラブの年度登録で、架空の年会費を入力して登録と請求を試します。画面の金額は正式料金ではありません。
2. 会費画面で対象を「クラブ年会費」にして同額の入金を確認し、クラブ画面に戻って事務局承認を試します。
3. ライセンス情報を登録し、個人会員の申請でGeneralを申請します。JAFライセンスは必須です。運転免許がない場合は、免許番号と有効期限を両方空欄にできます。
4. 所属承認画面で承認し、会費画面でGeneral会費2,000円の入金を確認します。入金識別番号はクラブ年会費とは別の架空番号にしてください。
5. 会員証が有効になることを確認します。同じ申請・入金・架空CSVを再操作しても二重計上しません。

## 保険などの確認範囲

| 画面 | 試せること | 正式には実行しないこと |
| --- | --- | --- |
| Temporary | 申請、クラブ代表の立場で主催承認、500円の入金。同日別イベントは拒否 | 本番申請。当日取消・返金なし、Generalは新規登録という方針は確定済み |
| スポーツ安全保険 | Generalの加入意思、架空人数、確認用Excel。初回4名の条件を表示 | 正式加入・提出・請求。2027年の料率・期間・追加加入条件は確認待ち |
| ゆうちょCSV | 固定の架空CSVの再取込、一意候補と複数候補の手動確認 | 実CSVの取込。名義末尾IDは不要で確定済み |
| 入金先・決済URL | 架空の口座・URL・取込元の組合せ | 実際の口座設定や決済案内の更新 |
| 協議会見舞金 | 今回は請求対象外であることの説明 | 申請入力・送信・審査・給付 |

保険Excelには「確認用・提出不可」と表示します。人数条件を満たしても正式加入にはなりません。スポーツ安全保険の事故後の連絡は、加入意思とは別の機能です。被保険者名とクラブ名の2項目で連絡する要件ですが、正式な送信画面はまだありません。ジムカーナ部会救済基金も独立した制度です。

## 情報ページや事務局の業務

お知らせ、イベントカレンダー、資料BOX、会則・シリーズ規則、関連リンクは、架空の入力と一覧を確認できます。ハンドブック冊子は廃止方針です。記事・カレンダーは事務局員が編集し、事務局長が承認する方針で、実際の公開には接続していません。

資料BOXの運営委員会資料は、確認画面では事務局だけが扱います。公開を選ぶと保存できません。実ファイルのアップロードは行いません。会議・表彰式の出欠、問い合わせ、通知文案も確認用の下書きです。

「旧HPの情報ページを確認」から、引継ぎページの一覧・詳細・検索・カレンダーを閲覧できます。ここも事務局限定です。主催者の実データ照会、正式なシリーズポイント集計、一般公開、実資料の移行は保留中です。

会員情報の画面で訂正・削除の例を試しても、本番の個人情報は変わりません。削除対象はポータル会員個人情報のみで、共通アカウント・過去エントリー・請求入金・操作ログは残す方針です。

## 困ったとき

| 状況 | 対応 |
| --- | --- |
| 確認画面に入れない／403と表示される | 事務局権限のあるアカウントか、担当者へ確認してください。新しい会員登録は不要です |
| ボタンやダウンロードがない | 「確認する立場」で事務局へ戻します |
| 赤い入力エラーが出る | エラーに書かれた項目を直して、もう一度押します |
| 「別の操作で画面が更新」と出る／409と表示される | 同じ画面を開き直します。確認画面を複数のタブで同時操作しないでください |
| 会員証が無効になった | 入金・承認・停止・架空の確認日で表示が変わります。最初の例へ戻すには一覧の「会員証の例を見る」を押します |
| メモが消えた | サインアウト・初期化・期限経過で戻せません。終了前にファイルへ保存してください |

解決しない場合は、画面名、押したボタン、表示された説明を確認メモやGoogle回答表に残してください。パスワードや実在会員の個人情報は書かないでください。
