# クラブ登録の操作練習

## まず開くページ

https://portal-test.gymkinki.com/ を開いてください。最初に出る認証欄へ、技術担当から受け取った「入口ID」と「入口パスワード」を入力します。サインイン用のメールアドレス・パスワードは、その後に開く操作手順のページに載っています。本番のパスワードは使いません。

このサイトは練習専用です。間違えても本番は変わりません。実在する名前・住所を入力せず、銀行への振込はしないでください。各画面の上に「操作練習専用」と表示されます。「操作手順へ戻る」で、この説明へ戻れます。

## 3つの役を順番に使います

- クラブ役：申請と、差し戻された内容の訂正をします。
- 事務局役：差し戻し、既存クラブとの照合、請求、最後の承認をします。
- 財務役：銀行明細を確認したことにして、架空の入金を記録します。

役を変えるときは、画面上の「サインアウト」を押してから次の役で入ります。最初はブラウザーのタブを1枚だけ使ってください。別のタブを開いても、サインイン中の役は同じです。途中でパスワードを忘れたら、入口の操作手順へ戻って確認できます。新規アカウントの登録やパスワード再設定は使いません。

## 入力する架空データ

| 項目 | 入力する内容 |
| --- | --- |
| 年度 | 2027 |
| 更新候補 | 199981で検索し、「練習更新クラブ／TEST-UPDATE」を選ぶ |
| 登録方法 | 更新 |
| JAF登録番号 | 99981 |
| JAF格式 | 公認クラブ |
| 会員区分 | 正会員 |
| クラブ名・略称 | 練習更新クラブ／TEST-UPDATE |
| 郵便番号・住所 | 0000000／練習専用住所 |
| 電話・携帯電話 | 0000000000 |
| 代表者氏名・ふりがな | 練習 代表／レンシュウ ダイヒョウ |
| 代表者メール | 操作手順にあるクラブ役のメールアドレス |
| 連絡担当者 | 「代表者と同じ」を選ぶ |
| 所属支部 | 大阪の項目を選ぶ |
| クラブの口座情報 | 空欄 |

「既存エントリーの自分の情報を入力候補に使う」からも架空の情報を取り込めます。検索や画面移動の後は、必須欄が埋まっているか確認してください。今回の更新は年会費50,000円・入会金0円、合計50,000円です。

## 練習の順番と確認する結果

1. **クラブ役**で申請します。「クラブ登録の申請」で上の架空データを入力し、「申請を提出する」を押します。表示された申請番号をメモしてください。結果は「更新：事務局の照合待ち」です。
2. **事務局役**で差し戻します。事務局の申請一覧から、メモした番号の申請を開きます。理由に「練習：クラブ名の末尾に確認済を付けてください」と記入し、「理由を添えて差し戻す」を押します。
3. **クラブ役**で訂正します。自分の申請を開き、クラブ名を「練習更新クラブ確認済」に直します。「訂正して再申請する」を押し、同じ申請番号で戻ることを確認します。
4. **事務局役**で照合します。同じ申請を開き、「提出後の事務局照合」で練習更新クラブを選びます。固定5桁は99981です。照合のチェックを付け、「照合結果を年度登録へ接続する」を押します。まだ請求・入金・最後の承認は終わっていません。
5. **事務局役**で請求を表示します。「クラブ会費・承認」で該当クラブを選び、「請求と振込案内を発行する」を押します。請求50,000円・残額50,000円と、架空口座の「振込禁止」を確認します。実際の振込はしません。
6. **財務役**で10,000円を記録します。同じクラブを開き、「実際の入金日」に今日以前の日付、「入金額」に10000、「銀行の取引番号」にTEST-申請番号-1と入力します。「銀行明細と照合して記録する」を押すと、残額は40,000円です。まだ年度登録済みになりません。
7. **財務役**で残り40,000円を記録します。入金日を入れ、金額40000、別の取引番号TEST-申請番号-2で記録します。残額0円になりますが、最後の年度承認はまだです。財務役には年度承認のボタンがありません。
8. **事務局役**で年度承認します。同じクラブを開き、満額入金のチェックを付け、「年度登録を承認する」を押します。「年度登録済み」と操作履歴を確認できれば、一通りの練習は完了です。個人会員受付や年度資格の判断元は切り替わりません。

取引番号の「申請番号」は最初にメモした数字へ置き換えてください。たとえば申請番号1ならTEST-1-1とTEST-1-2です。これらは架空の入金を区別するための番号です。

## 困ったとき・修正をお願いするとき

- 別の更新があると出たら、一覧から同じ申請を開き直します。新しい申請を何件も作る必要はありません。
- 受付準備中・ボタンが押せない場合は、URLにportal-testが含まれるか確認し、役・画面名・申請番号を技術担当へ伝えてください。本番を開放する必要はありません。
- 最初からやり直したい場合は、技術担当へ「練習データを初期化してください」と伝えます。他の人が練習中なら、先に終了するのを待ってください。初期化すると練習の申請・請求・入金が消え、サインインし直す必要があります。本番は変わりません。
- できなかった操作は「使った役／画面名／申請番号／押したボタン／どうなったか／期待していた結果」をメモしてください。パスワードを報告へ貼らないでください。

練習できたことと、本番の受付開始を承認することは別です。本番の受付開始と権限付与は保留しています。
