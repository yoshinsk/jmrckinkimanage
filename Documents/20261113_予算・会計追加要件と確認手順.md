# 予算・会計機能の追加要件と事務局の確認手順

2026年11月13日

## 今回追加する機能

手計算している予算管理をポータルで扱うため、年度・科目ごとの予算と収支実績を比較する機能を追加します。正式な科目、予算の承認者、年度途中の補正方法はまだ不明です。まず事務局専用の検証画面で操作を確認し、回答を受けて正式運用の設計を確定します。

今回の検証画面では年度予算、収支報告、監査用明細、貸借対照表、ゆうちょ・ペイメントコアCSVの形式、クラブ申請項目、通知文面を確認できます。画面の入力はログイン中の確認データにだけ反映します。正式な予算帳簿や会費・入金・会員資格には登録しません。

ペイメントコアの名義末尾に数字があってもエントラントIDとは判定しません。電話・メールを解析結果や照合キーに複写せず、同内容の行も別取引の可能性があるため削除しません。銀行へのまとめ振込と決済明細の照合は、対応資料が届くまで保留します。

## 画面の開き方

1. [JMRC近畿ポータル](https://gymkinki.com/manage/)へ、いつものアカウントでサインインします。
2. 「事務局の設定」から「予算・会計と追加資料の確認」を選びます。「機能の操作確認」からも開けます。
3. 最初に「事務局専用の検証画面です」と表示されることを確認します。架空のクラブ会費30,000円と個人会費2,000円が入っています。
4. 実際の氏名や会計記録を入力せず、確認用の数字で試してください。

事務局と同等の権限を持つ担当者だけが開けます。一般会員はURLを直接開いても閲覧・操作できません。

## 年度予算を試す

1. 「年度予算」を選びます。表示する年度を変える場合は、年度を入力して「年度を表示する」を押します。
2. 科目ごとの予算額を入力し、「確認用予算に反映する」を押します。空欄は未入力、`0` は予算0円です。
3. 下の「予算と収支の比較」で実績、残額、執行率を確認します。
4. 終了前に「予算をCSVに保存」を押し、ダウンロードしたファイルを保管してください。
5. 次回は「保存した予算CSV」でそのファイルを選び、「予算CSVを読み込む」を押します。同じ年度の確認用予算を置き換えます。

残額は「年度予算－集計終了日までの累計」です。例えば、会議費の予算10,000円に対して支出12,000円なら、残額は－2,000円、執行率は120％です。予算が0円または未入力の場合、執行率は計算しません。スマートフォンで表の右側が見えない場合は、表の中を左右に動かしてください。

入力内容はこのサインイン中だけ保持します。2時間経過後の再表示、サインアウト、初期化で利用できなくなります。予算以外の入力内容を再読込する機能はまだありません。正式運用では確定予算・補正履歴・承認履歴の保存方法をF13の回答に基づいて設計します。

## 収支・貸借・CSVを試す

| 確認すること | 操作 | 確認する表示 |
| --- | --- | --- |
| 期間の収支 | 「収支報告・監査出力」で年度、開始日、終了日を指定 | 期間の収入・支出・差額と、年初からの累計が分かれている |
| その他の支出 | 同じ画面で適用日、項目、金額、明細、備考を入力 | 指定した科目の支出と予算残額が変わる。登録日と適用日は別に保持する |
| 会費の再連携 | 「架空の会費を再連携する」を繰り返す | 同じ会費が増えない。実際の会費は読み込まない |
| 手元で確認 | 収支報告・監査用明細のCSVを保存 | 「操作確認専用」と書かれた帳票が得られる |
| 月末残高 | 「貸借対照表」で各科目の現在額と比較残高を入力 | 差額を計算する。不足分を自動で補わない |
| 月末確定の例 | 前月以前を選び、全科目を入力して貸借を一致させる | 確認用に確定できる。その月の追加入力や再連携は止まる |
| ゆうちょの形式 | 「CSVの形式確認」から架空CSVを保存し、UTF-8で読み込む | 入金1件と、入金対象外の支出1件を表示する |
| ペイメントコアの形式 | 架空CSVを保存して種類を選び、読み込む | 支払額2,000円、手数料100円、差引額1,900円。年が未入力なら日付は未確定 |

月末確定は操作例です。正式な承認、締め解除、実際の会計記録には接続しません。やり直す場合は、必要な予算CSVを保存してから、画面末尾の「確認用データを初期化する」を押してください。

クラブ申請の入力例は「クラブ申請の入力項目」で確認できます。「通知文面」には保険手続き完了と2028年度以降の更新案内の候補があります。通知を保存する場合は「通知文面を下書きに保存する」から既存の下書き画面へ進み、用途と文面を入力します。下書きは暗号化して保存しますが、メールは送りません。

## 運営者に回答してほしいこと

[既存の回答表](https://docs.google.com/spreadsheets/d/1z0WuTupTRBSXgzMNBRjosTNgOi13HyVPYtn1knIsato/edit#gid=202611011&range=A81:I101)の「整合性チェック_20261101」に、受領要望N01～N08と追加確認F01～F13を追記しました。過去の質問・回答は残しています。回答が必要な行は黄色のD・E列へ記入してください。

| ID | 確認する内容 | 判断が必要な理由 |
| --- | --- | --- |
| F01 | 会計年度、開始残高、年越し処理 | 集計期間と初期残高を確定するため |
| F02 | 正式な科目、予算、Excel原本、帳票形式 | 資料内の異なる帳票例を正式な科目・予算として採用できないため |
| F03 | 会費の計上時点、前受、分割、訂正、返金 | 請求と入金のどちらを実績にするかで金額と年度が変わるため |
| F04 | 入力権限、承認、月締め、締め解除 | 誰が確定・訂正できるかが未確定のため |
| F05 | 保存対象と保存期限 | 「3年分」と「2027年分は2030年末まで」の表現を確認するため |
| F06 | スポーツ安全保険の会計範囲 | 収入管理の対象外という説明と、保険補助費の科目例を整理するため |
| F07 | Temporaryの500円は年単位かイベント単位か | 追加PDFの年額表記と、確定済みの1イベント500円が異なるため。回答までは既存のイベント単位を維持 |
| F08 | クラブ申請の必須項目、掲載先、送付先、登録証 | 入力項目だけで公開や添付義務を決めないため |
| F09 | 保険完了通知の文面、宛先、完了条件、保存項目 | 入金確認を保険手続き完了と取り違えないため |
| F10 | ペイメントコアの西暦年、取引ID、決済・取消状態 | 提供CSVだけでは取引を一意に確定できないため |
| F11 | 手数料の計上と銀行まとめ振込との照合 | 総額・差引額の混同と二重計上を防ぐため |
| F12 | 指定名義欄の案内からIDを外すか | 提供CSVの旧見出しと、C03の「名義末尾ID不要」が異なるため |
| F13 | 予算の入力者・承認者・確定時期・補正・配分 | 年度予算だけか、月別・部会別にも管理するかを確定するため |

P20など既存の未回答事項も保留を続けます。登録受付、年度資格の参照先切替、一般公開、実メール送信、個人情報の削除は開始しません。既存ダートラの受付設定は変更しません。
