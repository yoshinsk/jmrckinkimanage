## 2027年度のクラブ料金

| 会費区分 | 正会員の年会費 | 賛助会員の年会費 |
| --- | ---: | ---: |
| 公認 | 50,000円 | 50,000円 |
| 加盟 | 30,000円 | 30,000円 |
| 準加盟 | 20,000円 | 20,000円 |
| 登録団体 | 20,000円 | 10,000円 |
| 関連団体・企業 | 対象外 | 50,000円 |

新規のクラブ・登録団体は、この年会費に入会金10,000円を加算します。更新・再加入・関連団体／企業には入会金を加算しません。計算処理は年度・会員区分・会費区分・登録方法を明示して使い、未設定の年度や数字コードから金額を推定しません。

既存の請求・入金は書き換えません。新規か再加入かの履歴照合、賛助のコード対応、用途別口座・請求マスターの設定を確認した後に、受付開始と請求への接続を判断します。

## 役職と初期設定

| 登録を承認する人 | 承認できる役職 |
| --- | --- |
| 承認者 | 事務局・運営委員 |
| 運営委員 | 承認者 |
| 事務局だけの人 | 上記の役職登録は承認できない |

本人の登録申請は、役職を兼任していても承認できません。運営委員長・副委員長・事務局長は「承認者」に統一します。記事・カレンダーの事務局長承認など、個別に決まっている業務の担当条件も保持します。

初期担当者は、チャットで指定された既存アカウントです。承認者と運営委員を初期設定し、元の事務局権限・既存entryの役割・パスワードは維持します。初期設定は外部運営者の指定を根拠とするため、通常の承認者欄には本人IDを入れず、別の根拠欄と操作ログに記録しました。通常の申請処理から、この初期設定の経路は使えません。

旧 `FINANCE` コードは互換用の別名として残します。事務局と同じ業務権限に揃えますが、今回の事前確認では、このコードを持つ本番アカウントは0件でした。事務局以外の既存ユーザーを一括で昇格させません。

## 原本との違いと、AIで読み取れる範囲

[旧HPの会則](http://www.jmrc-kinki.net/kaisoku.html)には、他地域でも近畿の事業として競技会を主催するJAFクラブを正会員とする例外があります。C07の回答との関係を確認中です。同会則の未更新後の新規扱いと入会金についても今回のC08と差があるため、2027年度の規程には今回の決定を明記する必要があります。

[2026年ジムカーナ規則](http://www.jmrc-kinki.net/_userdata/2026_gymkhana_regulation.pdf)のPDF7～8ページ（印刷ページ29～30）と、[2026年ダートトライアル規則](http://www.jmrc-kinki.net/_userdata/2026_dirttrial_regulation.pdf)のPDF9～10ページ（印刷ページ49～50）を画像でも確認しました。両資料には、成立条件、端数処理、段階的な同点比較、表彰人数の規定があります。ただし、全戦を数える条件が「5戦未満」であること、同点比較の途中に全得点を使う段階があることは、今回のC15と異なります。

今回の判定は最新回答の「5戦以下」「有効戦のみ」を採用します。原本からは年度・競技・シリーズ・ページ・条件・例外を付けた下書きを作れますが、2026年の規定を2027年へ自動採用しません。正式な2027年原本を受け取り、差分を部会で確認してから、配点・同点順位・自動取込を接続します。

## 事務局で試す手順

1. [マイページ](https://gymkinki.com/manage/)へサインインし、「機能の操作確認」を開きます。
2. 「正会員クラブの年度登録」で料金計算の区分・会員区分・登録方法を選び、「2027年度の料金を計算」を押します。賛助の登録団体を新規で選ぶと、年会費10,000円・入会金10,000円・合計20,000円になります。
3. 上の「確認する立場」で運営委員に切り替え、「年度設定・権限・移行・保存方針」を開きます。「登録する役職」を承認者、「登録対象」を別の架空担当者にして、承認可否を試します。本人を選んだ場合は拒否されます。
4. 同じように承認者の立場へ切り替え、別の架空担当者の事務局・運営委員登録を試します。この切り替えでは、実在アカウントの権限は変わりません。
5. 「会則・シリーズ規則」を開き、「成立した当該クラスの戦数」を6、「シリーズは終了したか」を「終了」にして、「成立条件・有効戦数・表彰人数を試算」を押します。有効戦数は4戦です。年間台数70・対象競技会7の例では、表彰人数の上限は5名になります。正式な分母はまだ確認待ちです。
6. 「通知・承認依頼の文面」で「表彰案内の文案を作る」を押します。未送信の案内が表示されます。メールは送られません。
7. 「スポーツ安全保険・確認Excel」にある「保険請求の連絡例」で、架空の氏名・クラブ名を入力し、「請求連絡の2項目を確認する」を押します。本人確認の手順もここに表示します。
8. 気づいた点を確認メモへ書き、終了前にExcel用CSVへ保存して担当者へ渡してください。保存だけでは他の人へ共有されません。

Generalの競技・審判員種別は「個人会員の申請」で確認できます。保有しない側には「なし」と入力します。実際の個人会員受付は引き続き保留です。

## 本番変更と復元の対象

追加するのは、会員種別申告の空テーブル、初期権限の根拠列、職務・権限定義、指定アカウントの初期職務、および許可した23ファイル（当初21ファイルと保険説明2ファイル）です。既存会員情報、entry履歴、請求・入金、年度の正本設定、受付フラグは維持します。追加した申告種別もポータルの個人情報として扱い、将来の削除範囲から漏らさないようにします。

DB適用前の状態と復元用コードはWeb非公開領域へ保存します。コードは元のファイルを保存してから置き換え、PHP構文と配置後のハッシュを確認します。障害時はコードを戻してから、役職・権限と空の追加構造を戻します。後続の権限変更や新しい申告データがある場合は自動復元を止め、データを保持します。

本番反映後も既存の事務局・エントラントのサインインと保留設定を確認しました。検証結果・適用先・バックアップ先は、[検証・復元記録](phase2/20261103_追加回答反映・検証・復元.md)に記録しました。
