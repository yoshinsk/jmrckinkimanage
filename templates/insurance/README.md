# スポーツ安全保険の指定様式

原本: [運営者指定のExcel](http://www.jmrc-kinki.net/_userdata/sports.security.insurance_form_club.xlsx)（回答入力 INS-03）。2026-10-29取得。

SHA-256: `ec52243187269f4cb84a28a7fad445eb3b20eb667e2854ee46950d82d0a59613`

指定URLのHTTPから取得した原本を変更せず保存する。HTTPSは証明書の検証に失敗したため使用していない。外部ファイルの自動差替えは行わず、原本更新時は項目・書式・料率の再確認、コードのハッシュ更新、隔離検証が必要。

アプリはWeb非公開の原本を複製し、指定セルだけを書き換える。原本の料率2,000円/1,200円と4名条件を現年度要件に採用しない。出力では確認用・提出不可とし、年齢・区分・人数別掛金・合計・振込欄は空欄、条件は確認待ちとする。旧計算式とcalcChain参照は除去し、他パーツを保持する。様式上の罫線・結合・列幅・行高・印刷設定を保つため、アプリはOOXMLを直接編集する。

`InsuranceWorkbook`はPHP ZIP/DOM拡張がない場合や原本ハッシュが異なる場合に503で停止する。本番ではこのフォルダーを公開ルートへ置かない。
